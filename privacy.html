プライバシーポリシー

最終更新日：2026年11月8日

1. 取得する情報

本ツールは、Google OAuth により許可された範囲で、運営者本人の Gmail のメッセージ情報（件名・送信者・ラベルなどのメタデータ）にアクセスします。

2. 利用目的

取得した情報は、運営者が指定した条件に従ってメールにラベルを付ける・整理するためだけに使用します。

3. 保存と第三者提供

メールの内容を外部に保存・送信することはありません。処理に必要な認証トークンは、運営者が管理するクラウド環境（AWS）に暗号化して保存します。取得した情報を第三者に提供・販売することはありません。

4. Google API サービスのユーザーデータポリシー

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

5. アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/permissions）から、いつでもアクセス権を削除できます。
